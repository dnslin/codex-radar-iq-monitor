Codex Radar IQ Monitor does not collect, transmit, sell, or share
personal user data.

The extension stores only the following information locally in Chrome:

- Theme preference
- Refresh interval
- Notification preference and change threshold
- Current and previous public RadarBench score snapshots
- Recent score changes and unread status

The extension communicates only with:
https://codexradar.com/

This communication retrieves the public RadarBench model/effort catalog
and aggregate benchmark scores. Score requests contain the model and
effort being monitored. They do not contain personal credentials,
browsing history, or the user's Chrome data.

The extension does not read webpage content or access browsing history.
